# 迷茫时候看看古人是怎么找到适合自己的道的？

面向文学历史爱好者与社交媒体（如小红书）分享传播的**诸子百家心性镜像测试**纯静态互动网站。以黑白水墨宋画留白美学为基调，通过 12 道明确而有张力的日常与人生情境抉择，为你算出与**儒家、道家、法家、墨家、兵家、纵横家**六大流派的精确契合百分比与主辅导向报告，并可一键生成 1080×1920 高清竖版水墨签文长图。

---

## 核心特色

- **明确情境抉择，告别模棱两可**：12 道高代入感问题（危机应变、团队拖延、借钱边界、非议应对、独处长假、职业岔路等），每题四个明确可行的行动选择，严格对称权重计分，使用最大余额法确保六家百分比之和严格等于 `100%`。
- **导向型复合命格报告**：不仅给出“如 35% 法家 · 25% 道家”的主辅分布，还内置全覆盖 `6 × 6 = 36` 种主辅组合判词、SVG 水墨六维雷达图、先贤迷茫寻道历史故事与“当下立刻能做的一件小事”。
- **黑白水墨视觉与长图生成**：宣纸纹理底色、朱砂篆印点缀、正片叠底水墨融合，并自带纯原生 Canvas 绘制的 1080×1920 竖版水墨签文分享图，无需后端即可随时保存分享。
- **诸子百家十家典籍录**：除 6 大核心测试流派外，另附农家、名家、阴阳家、杂家典籍与现代迷茫解药，随时查阅。
- **零依赖纯静态架构**：不依赖构建工具与外部框架，同时支持直接双击本地 `index.html`（`file://`）或挂载至任意静态托管平台。

## 文件结构

```text
.
├── index.html                  # 页面骨架（卷首 / 问答 / 推演 / 结果四幕与双弹窗）
├── css/
│   └── style.css               # 黑白水墨宣纸视觉系统与移动端响应式样式
├── js/
│   ├── data-schools.js         # 六大核心流派 + 36 种组合判词 + 四家补充典籍
│   ├── data-questions.js       # 12 道明确情境测试题与严格对称权重矩阵
│   ├── scoring.js              # 主(+3)次(+1)计分引擎与最大余额法百分比归一化
│   ├── visuals.js              # SVG 水墨雷达图与 1080x1920 Canvas 签文长图生成器
│   └── app.js                  # 视图状态机、交互逻辑与剪贴板复制
├── assets/
│   └── images/
│       ├── hero-ink-mountains.jpg   # 首屏 AI 生成水墨远山孤舟背景图
│       ├── ink-divider-brush.svg    # 答题卡横向飞白墨迹装饰矢量图
│       └── school-*.svg             # 儒、道、法、墨、兵、纵横六家水墨意象矢量图
├── scripts/
│   └── verify-logic.mjs        # Node.js 题库对称性与计分压力校验脚本
└── README.md
```

> **水墨素材说明**：`hero-ink-mountains.jpg` 为 AI 生成的宋画意境水墨山水图；`ink-divider-brush.svg` 与六家 `school-*.svg` 采用高精矢量水墨（含飞白与淡墨滤镜）构建。如需后续替换成个人定制位图，只需替换 `assets/images/` 下对应文件并同步 `index.html` 与 `js/data-schools.js` 中的路径即可。

## 本地运行与生成镜像链接

### 方式一：本地直接查看
- 最简方式：直接双击根目录下的 `index.html` 在浏览器中打开即可使用全部测试、雷达图与长图导出功能。
- 本地服务方式（推荐开发调试）：
  ```bash
  python -m http.server 8765
  ```
  随后浏览器访问 `http://localhost:8765/`。

### 方式二：校验题库与计分逻辑
```bash
node scripts/verify-logic.mjs
```

### 方式三：部署为可分享的公开镜像链接
本项目为纯静态站点，上传整个目录即可生成公开访问链接：
- **GitHub Pages**：推送到 GitHub 仓库后，在 `Settings -> Pages` 选择主分支根目录部署，数分钟内获得 `https://<用户名>.github.io/<仓库名>/`。
- **Cloudflare Pages / Vercel / Netlify**：直接拖拽整个项目文件夹上传即可即刻生成永久 HTTPS 分享链接，挂到小红书评论区置顶或个人简介引导访问。
