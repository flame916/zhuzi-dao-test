# 迷茫时候看看古人是怎么找到适合自己的道的？

面向文学历史爱好者与社交媒体（如小红书）分享传播的**诸子百家心性镜像测试**纯静态互动网站。以黑白水墨宋画留白美学为基调，通过 18 道附有先秦古籍微引的明确情境抉择，为你算出与**儒家、道家、法家、墨家、兵家、纵横家**六大流派的精确契合百分比与主辅导向报告，并结合原典精读、分场景破局指引与三阶落地路线图，一键生成 1080×1920 高清竖版水墨签文长图。

---

## 这一版怎么玩

首页可直接打开六家图鉴，比较同一件合作难题的六种解法。每家导读列出原句、篇名、白话讲解和可主动打开的原文链接。问卷、解读和签文导出均可离线使用。

选择「开始答题」答 18 道情境题，或选择「做完整测试」答完情境题后再做 12 道自评。后者按情境六成、自评四成合并。在允许本地存储的浏览器中，返回卷首或刷新后可续答。结果页提供答题回顾，可查看具体选项贡献的分数。

分享首页时可在网址末尾加上 `#quick` 直达 18 题，或加上 `#full` 直达 30 题。同模式有本地进度时会接着上次作答。

## 核心特色

- **18 道明确情境问心 + 古籍微引**：涵盖危机应变、团队拖延、借钱边界、非议应对、独处长假、职业岔路、跨界试水、顺境自持等 18 个高代入感抉择，每题附有先秦典籍微引与四个明确可行的行动选项，采用严格对称权重计分与最大余额法确保六家百分比之和严格等于 `100%`。
- **强指引导向型报告**：除给出“如 35% 法家 · 25% 道家”主辅分布、`6 × 6 = 36` 种复合命格判词、SVG 水墨六维雷达图外，还提供**本命原典精读（含出处与白话精解）、推荐书单、四大现实场景（职业/人际/情绪/抉择）破局指引、重大决策自检三问**以及**今日/七日/一月三阶行动路线图**。
- **黑白水墨视觉与长图生成**：宣纸纹理底色、朱砂篆印点缀、正片叠底水墨融合，并自带纯原生 Canvas 绘制的 1080×1920 竖版水墨签文分享图，无需后端即可随时保存分享。
- **诸子百家十家典籍录**：除 6 大核心测试流派外，另附农家、名家、阴阳家、杂家典籍与多则原典摘录，随时查阅。
- **零依赖纯静态架构**：不依赖构建工具与外部框架，同时支持直接双击本地 `index.html`（`file://`）或挂载至任意静态托管平台。

## 文件结构

```text
.
├── index.html                  # 页面骨架（卷首 / 问答 / 推演 / 结果四幕与三个弹窗）
├── css/
│   ├── folio.css               # 卷首、原典导读与问卷交互样式
│   └── style.css               # 黑白水墨宣纸视觉系统与移动端响应式样式
├── js/
│   ├── data-schools.js         # 六大核心流派深度指引 + 36 种组合判词 + 四家补充典籍
│   ├── data-questions.js       # 18 道明确情境测试题与严格对称权重矩阵
│   ├── data-scale.js           # 可选自省卷的 12 则自评
│   ├── scoring.js              # 主(+3)次(+1)计分引擎与最大余额法百分比归一化
│   ├── visuals.js              # SVG 水墨雷达图与 1080x1920 Canvas 签文长图生成器
│   └── app.js                  # 视图状态机、交互逻辑与剪贴板复制
├── assets/
│   └── images/
│       ├── hero-ink-mountains.jpg   # 首屏水墨原图，页面按屏幕宽度加载 WebP 压缩版
│       ├── ink-divider-brush.svg    # 答题卡横向飞白墨迹装饰矢量图
│       └── school-*.svg             # 儒、道、法、墨、兵、纵横六家水墨意象矢量图
├── scripts/
│   └── verify-logic.mjs        # Node.js 题库对称性与计分压力校验脚本
└── README.md
```

> **水墨素材说明**：`hero-ink-mountains.jpg` 为 AI 生成的宋画意境水墨山水图；`ink-divider-brush.svg` 与六家 `school-*.svg` 采用高精矢量水墨（含飞白与淡墨滤镜）构建。如需后续替换成个人定制位图，只需替换 `assets/images/` 下对应文件并同步 `index.html` 与 `js/data-schools.js` 中的路径即可。

## 本地运行与生成镜像链接

### 方式一：本地直接查看
- 最简方式：直接双击根目录下的 `index.html` 在浏览器中打开即可使用全部测试、雷达图与长图导出功能。
- 本地服务方式（推荐开发调试）：
  ```bash
  python -m http.server 8765
  ```
  随后浏览器访问 `http://localhost:8765/`。

### 方式二：校验题库与计分逻辑
```bash
node scripts/verify-logic.mjs
```

### 方式三：部署为可分享的公开镜像链接
本项目为纯静态站点，上传整个目录即可生成公开访问链接：
- **GitHub Pages**：推送到 GitHub 仓库后，在 `Settings -> Pages` 选择主分支根目录部署，数分钟内获得 `https://<用户名>.github.io/<仓库名>/`。
- **Cloudflare Pages / Vercel / Netlify**：直接拖拽整个项目文件夹上传即可即刻生成永久 HTTPS 分享链接，挂到小红书评论区置顶或个人简介引导访问。
